# Dutch Open Datasets - Analysis Brief

## RDW Erkende Bedrijven
**Description:** Registry of 30,683 RDW-recognized businesses with addresses and API endpoints for detailed certifications.

**Use case:** Mapping authorized service providers, monitoring geographic distribution of certified workshops, compliance auditing.

**Readiness:** ⚠️ **Partial** – Address fields are fragmented (separate street/number/addition columns); postcode stored redundantly in numeric and alphanumeric formats. Requires light normalization before spatial analysis. API field suggests additional data available via linked resources.

---

## RDW Terugroep Actie Risico
**Description:** 5,089 vehicle recall risks with RDW reference codes mapped to hazard categories and descriptions.

**Use case:** Public safety analysis, recall campaign tracking, risk pattern identification across vehicle fleets.

**Readiness:** ✅ **Analysis-ready** – Clean structure with codes and human-readable descriptions. No apparent data quality issues. Can be joined to vehicle registration data via reference code.

---

## RDW Gebreken
**Description:** 1,004 vehicle defect categories with regulatory references, active date ranges, and dual timestamp formats.

**Use case:** Inspection standards reference, historical defect trend analysis, regulatory compliance mapping.

**Readiness:** ⚠️ **Partial** – Redundant date columns (integer YYYYMMDD + TIMESTAMP); sparse metadata (many nulls in article/paragraph). Useful as a lookup table but limited analytical value without linked inspection records.

---

## RDW GEO Carpool
**Description:** 127 carpool facilities nationwide with coordinates, capacity (parking/charging), and accessibility features.

**Use case:** Charging infrastructure planning, accessibility compliance monitoring, carpool adoption analysis.

**Readiness:** ✅ **Analysis-ready** – Structured location data, clear numeric fields. Note: coordinates stored as string tuples (requires parsing); accessibility field has many nulls but usable for subset analysis.
